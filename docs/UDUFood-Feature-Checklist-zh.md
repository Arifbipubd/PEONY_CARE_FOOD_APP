# UDUFood — 功能清单（一页）

给市场团队用。带餐厅老板按 **1 → 10** 讲。讲完一项就勾一项。

**用词：** 一律说 **配套餐 / complementary meal**，不要说“免费餐”。品牌一律 **UDUFood**。Donor 模块暂不讲 — 不要提赞助或付款。

**距离：** 领取者不需要在 500 米内。默认能看到 **5 公里**内的列表。可在定位设置里改成 **1 / 2 / 3 / 5 / 10 公里**。到店领取 — 进店扫描食物二维码。

---

- [ ] **1. 手机登录与两个角色**  
  登录只用手机号 + OTP。两个角色：**餐厅**（发布剩余食物）和 **领取者**（每天领取一份配套餐）。电邮只用于发票，不是登录方式。

- [ ] **2. 餐厅注册 — 立即进入**  
  餐厅用营业资料和 **UEN** 注册。**无需等待审核**。注册完成后立刻进入餐厅后台，马上可以发布。

- [ ] **3. 发布配套餐**  
  在首页点 **Post**。填写菜名、类别（饭、面、熟食、烘焙等）、数量（份 / 盒 / 包…）、可选照片、备注，以及排期：**一次**、**每天**，或 **指定日期**。发布永远不收费。

- [ ] **4. 柜台二维码**  
  发布后，该列表会生成 **QR 码**。可打印或直接亮在手机上。领取者到店扫描 **食物二维码**。这一扫就是领取 — 系统 **自动标为 Collected（已领取）**。餐厅不用确认，也不用再点任何按钮。

- [ ] **5. 领取者如何找到餐厅（默认 5 公里）**  
  领取者浏览 **附近** 的餐食和餐厅。默认搜索范围是 **5 公里**。可在设置里改成 **1、2、3、5 或 10 公里** — 选多少，就看到多少。每条列表会显示距离（例如 1.2 公里）。

- [ ] **6. 搜索、筛选与餐厅主页**  
  领取者可按名称搜索，切换 **餐食 / 餐厅**，按类别和距离筛选。点进餐厅会打开公开主页（菜单照片、地址、当前列表）。

- [ ] **7. 即时领取 — 每天一份**  
  领取者打开列表、到店、扫描 **该食物的二维码**。餐食会 **立刻领取并自动标为 Collected**。限额：每个领取者 **新加坡日历日 1 份**配套餐（新加坡时间午夜重置）。食物没了会显示不可用。当天已领取过会看到每日限额页面。

- [ ] **8. 今日领取看板**  
  餐厅打开 **Claims** 查看今日领取。扫描食物二维码后已经是 **Collected** — 员工不用手动点已领取。如果有人没来，标 **No-show（未到）** — 该份会回到池里，别人可以再领。

- [ ] **9. 管理列表**  
  **Manage** 有进行中 / 过往 / 已关闭。随时可关闭列表（卖完或要停）。之后可再启用。可改详情。固定剩余食物可设每天 / 指定日期，不用重复输入。

- [ ] **10. 首页、资料与其他**  
  **Home** 显示今日数字（已发布、已领取、剩余）。公开主页用的 **菜单照片**。有人领取时有 **通知**。**数据分析**（哪些动得快、领取率）。**资料** 可改店铺信息、位置、帮助。餐厅合作伙伴 **发布免费**。
